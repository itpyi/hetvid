# Agent Entry Point

## What to read at the start of every session

1. **`.agent/rules/general.md`** — standing rules that apply to every task (workflow, commits, doc maintenance, pitfall system).
2. **`dev-doc/doc.md`** — project architecture master index; drill into module docs only as needed.
3. **`.agent/skills/publish.md`** — read *only* when the task involves publishing a release.

## What stays outside `.agent/`

| Path | What it is |
|------|-----------|
| `dev-doc/` | Project architecture and module documentation |
| `dev-pitfalls/` | Past bug records (created on demand) |
| `todo.md` | Current task list |
| `prompts/` | Human prompt templates — **do not read autonomously** |
