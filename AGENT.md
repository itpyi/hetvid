# Agent Entry Point

## What to read at the start of every session

1. **`.agent/rules/general.md`** — standing rules for every task on any project (workflow, commits, docs, pitfall system).
2. **`.agent/rules/project.md`** — project-specific conventions (role, changelog, doc separation).
3. **`dev-doc/doc.md`** — project architecture master index; drill into module docs only as needed.
4. **`.agent/skills/`** — read a skill file *only* when the task requires it (e.g., `publish.md` when publishing).

## What stays outside `.agent/`

| Path | What it is |
|------|-----------|
| `dev-doc/` | Project architecture and module documentation |
| `dev-pitfalls/` | Past bug records (created on demand) |
| `todo.md` | Current task list |
